# 实验 contracts

`o2c_experiments.json` 写的是结果出来前就必须固定的实验事实，不写任何“应该涨多少”的结果阈值。

它约束五类问题：

1. **标签与日期**：所有实验只认下一交易日 O2C；2024 完整样本是 241 个因子日。
2. **训练边界**：E1 的训练集与预测集之间保留一个完整交易日，未来日期不能改变既有 block。
3. **实验臂差异**：E3 四臂按嵌套结构增加模块；E5 两臂只允许输入通道不同。
4. **评分口径**：A 只含四项，完整 Barra 必须有 42 个回归量。
5. **交易核算**：E4 从现金建仓计入换手，成本按单边 bp 从当日收益扣除。

这些 contract 由 `../tests/` 的小型合成测试读取并核对当前代码。测试不读取正式结果、不需要 GPU，也不会启动训练。
