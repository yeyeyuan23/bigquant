# E3 — 渐进加法实验（O2C）

## 问题

从最简单的统计通路开始，每次只增加一个模块，观察 A 的四个小分如何变化。

## 四级模型

1. **P0：统计通路 + 打分头**：17 个通道各取均值、标准差、最后有效值、尾 30 分钟均值和有效占比，得到 85 个数；投影到 96 维后直接用 `96 → 64 → 1` 打分。
2. **P1：+ DeepSets**：在 P0 上加入股票横截面信息，再打分。
3. **P2：+ 投影和 TCN**：在 P1 上加入分钟序列投影及 3 个串联 TCN 块；用最后一个有效分钟的表示作为序列摘要，与统计通路融合。
4. **P3：+ mean 和 attention**：在 P2 的 `last` 之外再加入全天 `mean` 和 attention 摘要。这一级是完整架构，并与前三臂一样从零训练，不能复用其他收益口径的权重或因子。

## 固定协议

- 训练：2019–2023，expanding；测试：完整 2024 OOS。
- 训练和评价标签统一为下一交易日开盘到收盘收益 `ret_next_open_to_close`（O2C）。2024 年 242 个交易日中，最后一天没有下一日标签，因此完整 OOS 评价为 241 天。
- seeds：`20260801`、`20260812`、`20260823`。
- 每个新模型训练 3 epochs；宽度 96；TCN 卷积核 3/15/60，共 3 块。
- P0、P1、P2、P3 除逐级新增模块外，其余数据、掩码、损失、优化器和打分协议相同。
- 新结果只写入 `reports/dependencies/finals_pre/e3_progressive_add/o2c/`；旧口径产物不参与本表。

## 评价
