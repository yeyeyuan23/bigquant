# E4：冻结提交权重的私榜期 C2C 严格 OOS

使用正式 M_raw checkpoint（训练截止 2024-12-26），在 2025-01-02 至
2026-08-28 的私榜 15 分钟数据上按原提交代码构造 17 个通道并推理。整个
实验不更新权重。该 checkpoint 是历史正式提交权重，训练目标为 O2C；这里不把它改写成 C2C 训练模型，只按统一的 C2C 口径评价其样本外表现。

日期为 d 的因子只使用 d 当天数据；评价标签为下一交易日收盘相对前收盘的
复权收益 `ret_close_to_close`。平台未公开评分标签公式；C2C 是本项目统一的研究口径，不称作“平台标签”。评价只报告完整 42 项 Barra 中性化后的 A 四小分，并按连续
60 个交易日分块展示。换手回测采用多空各 20% 股票的等权目标仓位，成本按
单边 5、10、20bp 扣除。
