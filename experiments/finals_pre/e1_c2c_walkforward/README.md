# E1：C2C walk-forward

训练历史从 2019 年开始。先用 2019–2024 的历史训练，然后在 2025-01 至
2026-08 的私榜 1 分钟数据上，每增加 60 个交易日重新从零训练一次，并预测
紧接着的 20 个交易日。每个窗口在预测日前留一个完整交易日作标签隔离。
训练与评价统一使用 `ret_close_to_close`。

七个窗口共形成 140 个严格 OOS 预测日。统一用完整 42 项 Barra 中性化计算
A 四小分，并输出逐日 RankIC、每个 20 日块的四项结果和折线图。旧的
2023–2024 walk-forward 结果不参与本实验。
