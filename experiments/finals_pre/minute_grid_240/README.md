# 240 位分钟输入修正：三种子配对实验

2026-09-06 已完成预定的三个 seed：20260801、20260812、20260823，共六次训练。240 位与 242 位平均中性化 RankIC 分别为 0.028562、0.028406，平均 RankIC IR 为 0.684348、0.687640，平均多空 Sharpe 为 7.639835、7.388099。240 位的 Sharpe 在三个配对中都较高，其他三项为两次较高、一次较低，尚无全面改善的证据。修正的依据仍是匹配实际分钟时刻，不能把这次结果概括为已证明普遍优于 242 位。

完整均值、样本标准差、逐 seed 配对差值和审计见 [三种子结果](../../../reports/dependencies/finals_pre/minute_grid_240/additional_seeds_20260906/README.md)；[首组报告](../../../reports/dependencies/finals_pre/minute_grid_240/20260906/README.md)保留作为历史记录。新增两组北京时间 13:21 启动、15:31:49 完成，15:37 回收校验后关机；本地 30 分钟 schedule 已停用，结案状态见 [RUN_STATUS.md](RUN_STATUS.md)。

`run_two_more.py` 在训练前核对首次实验的源码与数据校验和，再依次运行两组配对；`summarize_pairs.py` 只接收完整的三个预定 seed，输出均值、样本标准差及配对差值。

将 active M_raw 输入改为 09:31–11:30、13:01–15:00，共 240 个固定时刻。缺失的真实分钟仍占自己的位置，不把后面的记录向前挤。17 个通道的数值、有效性标记、模型结构与损失保持原样。

每个 seed 均先训练 clock240，再训练 clock242。配对内使用相同 seed，均为 3 epoch、2019–2023 年历史、一个交易日标签隔离、2024 年 O2C 评价。每步一个交易日，最多 1200 只股票；D=96，核 3/15/60，3 个 TCN block，AdamW 4e-4，AMP。采用已有 Polars loader；每 50 步记录时间。训练最后保存 checkpoint，再推理 2024 年。四项评价沿用 E2 的行业与 Barra 中性化口径。

clock242 是修正前 c0dcd219 的**按时钟对齐版本**（空位在 0、121）。原始 submission 是另一个历史布局，尾部有两个空位；本次不把它与当前 242 位基线混称为同一实现。原始 submission、旧权重和旧成绩均保留。历史 E5 的 242 位兼容转换仍单独保留，它不参与本次 M_raw 训练。

`run_pair.py` 需要两个独立代码目录，分别保存修正前与修正后 src/fastpack；两个目录使用相同的 trainer，以保证进度记录与训练循环一致。输出 `pair_manifest.json`（源码/数据校验和及完整命令）、`status.json`、两个 checkpoint、OOS 因子、逐日中性化 RankIC、`comparison.csv/json` 和完整日志。必须核对 241 个评价日与相同股票日期键。

本次通过本地 schedule 轮询，全部完成后先把产物拉回本地，再执行 **autodl-bigquant 远程机器**的 `shutdown`。关机不由训练脚本执行。三个种子覆盖相同的 2024 年，只补充随机初始化的稳定性证据，没有增加独立样本外时期；当前展示里的历史成绩不能自动改称 240 位结果。
