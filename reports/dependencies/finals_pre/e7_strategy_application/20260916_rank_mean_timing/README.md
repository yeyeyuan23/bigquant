# 五日平均排名的时间顺序检查

调仓日 t 开盘使用此前五个交易日 t−5 至 t−1 的百分位排名均值。每天先在当天股票池内排名，再沿日期向后取五日窗口；回测在下一交易日开盘使用该信号。

2026-09-16 对现存输入和实际比较代码的检查通过：

- 输入与原结果的 SHA-256 一致，回测引擎和比较脚本均与原审计一致。
- 402 个日期的滚动排名逐日与手工切片计算核对，最大差为浮点误差 3.33e-16。日期来自按时间排序的行情交易日，与因子日期完全对应。
- 7 个截断时点均检查了排名和调仓后持仓。只保留此前数据，或改变未来分数、未来缺失值与下一日价格，所得历史持仓均完全一致。截断回测末日强制平仓的收益行单独排除，平仓前持仓仍参与核对。
- 400 个持有区间的净值、收益、成本和换手复现，最大差为浮点误差 2.22e-16。净年化 14.4897%，日均单边换手 0.517074，净最大回撤 −6.3074%。

现有规则会在最初四个调仓日使用已有的一至四日记录。后续五日窗口内，缺失排名不参与平均，且前一交易日有因子分数的股票才进入新目标。热身期后共有 653 条入选股票日记录使用了少于五个有效排名。因此，“五日平均”表示五个交易日的窗口，每只股票的有效观测数可以少于五个。逐日窗口边界和计数见 `rank_windows.csv`。

这次检查覆盖冻结分数之后的排名平滑与调仓时间顺序。原始行情、复权因子和 Barra 暴露的历史发布时间与修订情况，以及上游模型推理，未在本次重新核验。成交沿用原回测的开盘价理想化假设。五日规则由已查看时期的追加比较选出，策略选择仍需未见时段检验。

原协议中 `calendar days` 的文字与实现不一致：实际按行情表的交易日行数滚动。原协议快照保留，演示稿已按实际实现表述。
