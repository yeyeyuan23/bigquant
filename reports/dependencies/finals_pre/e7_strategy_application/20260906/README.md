# 历史记录：统一成本系数的应用比较

本目录保留每侧统一费率的历史结果。当前买入 3bp、卖出 8bp 与滑点情景见 [新结果](../20260906_fee_slippage/README.md)。原运行脚本冻结在 `code/`；复算旧结果可运行 `python code/validate_results.py --results .`。

四种预先指定的主配置在 10bp 下净年化均为负。排名缓冲区、三日调仓和部分调整降低了主配置的换手与回撤；结果同时依赖费率与调仓起点，不能概括成所有策略或所有情景都无效。

信号与仓位规则见 [E7 实验定义](../../../../../experiments/finals_pre/e7_strategy_application/README.md)。模型权重保持正式提交身份，训练截止 2024-12-26。应用回测为 2025-01-03 开盘至 2026-08-28 开盘的 400 个持有区间，包含隔夜；原 O2C 排序评价仍是 401 日 RankIC 0.025169。

## 估值与执行限制

缺开盘报价时不交易，以最近已经可见的价格估值。10bp 主比较中，每日和缓冲策略最后全部平仓；三日与部分调整的期末未平持仓绝对市值分别约为期末净值的 **0.55% 与 0.39%**，继续计入净值，未假设其已经卖出。18 个比较中最大占比约为 0.63%。缺报价不自动认定为停牌。

假设有报价即可按开盘价成交，且有无限借券额度。未验证涨跌停排队、开盘容量、借券费、融资或非线性冲击。使用复权价格近似公司行动。结果是统一假设下的研究比较，不是实盘可实现收益的确认。

当前评价时期已用于研究复盘，新增持仓规则的比较不产生新的独立测试期。任何据此选出的策略都仍需后续未参与选择的时段验证。
