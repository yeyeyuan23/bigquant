# 简单持仓规则追加研究 · 2026-09-16

目的：用更容易解释的规则替换演示稿中的“五分位混合调仓”。保持冻结因子、原始输入、400 个持仓区间、成交与计费口径相同。

## 规则与选择过程

运行前记录四个候选：每两日调仓、每五日调仓、三日平均排名、五日平均排名。原先首选解释候选是三日平均排名；查看完整结果和年度切片后，演示稿改用五日平均排名。因此，**五日窗口的选择属于已看过样本上的追加开发，不是独立样本外验证**。保留原始 `protocol.json`，不把事后选择改写成事前确定。

五日平均排名：每天先把各股因子分数转为当天股票池中的百分位排名（分数越高越好），再平均该股最近五个交易日的排名，包括当日。按平均排名取最高 20% 做多、最低 20% 做空，每天等权调整，多空各以净值的 100% 为目标。不足五日时使用已有记录；窗口内缺失排名不参与平均，当日因子缺失的股票不进入新目标。交易发生在信号形成后的次日开盘。

定期调仓：首次建仓后每两日或五日调整为当天五分位等权目标；两次调仓之间保持原股数。起点变化全部报告，不按最佳起点展示主结果。

## 基准费率下的结果

买入 3bp、卖出 8bp，额外滑点 0bp。净年化为日净收益算术均值乘 252，复合年化另存于 CSV 的 `cagr` 列。

| 规则 | 全期净年化 | 日均单边换手 | 净最大回撤 |
| --- | ---: | ---: | ---: |
| 每日五分位 | -7.64% | 1.410 | -14.75% |
| 排名缓冲区 | 4.37% | 1.163 | -8.10% |
| 每三日调仓 | 0.45% | 0.485 | -7.56% |
| 原五分位混合调仓 | 8.60% | 0.728 | -5.40% |
| 每两日调仓（起点 0） | 8.54% | 0.717 | -6.94% |
| 每五日调仓（起点 0） | 7.36% | 0.293 | -6.10% |
| 三日平均排名 | 8.97% | 0.727 | -9.06% |
| 五日平均排名 | 14.49% | 0.517 | -6.31% |

五日平均排名在 2025 / 2026 切片的净年化分别为 17.67% / 9.61%；2026 仅到 8 月。三日平均排名对应为 15.53% / -1.07%。年度切片不是新增独立验证样本。

每两日调仓的起点 0 / 1 净年化为 8.54% / 2.60%；每五日调仓的起点 0 至 4 为 7.36% / 15.69% / 6.44% / 7.47% / 10.09%。主表固定起点 0。

五日平均排名每侧额外加入 2bp / 5bp 滑点后的净年化分别为 9.27% / 1.45%。这些是假定可成交、可卖空情况下的研究结果；未包含最低佣金、借券费和非线性市场冲击。不能据此承诺实盘表现。

## 文件与复现

- `strategy_summary.csv`：全部候选、成本情景和定期调仓起点。
- `strategy_daily.csv`：逐日持仓区间、成交、费用、净值及回撤。
- `year_slices.csv`：2025 / 2026 的年度切片。
- `strategy_primary.csv`：首次比较保存的四种主规则。当前演示稿展示每日五分位、排名缓冲区、五日平均排名；原始结果保留。
- `audit.json`：输入及代码哈希、原有 18 个配置的复现误差、未来分数扰动检查。

输入保存在研究仓库本地 `data/runtime/finals_pre/e7_strategy_application/20260916/inputs/`，两个 parquet 的哈希见审计文件。运行 `python experiments/finals_pre/e7_strategy_application/compare_simple_strategies.py` 可复现比较；回测引擎位于同一目录。PRE 的 `support/scripts/update_strategy_slides.py` 读取这些结果制作页面。

五日窗口与调仓时点已单独复核，见研究仓库中的[时间顺序检查](../20260916_rank_mean_timing/README.md)。调仓日 t 使用 t−5 至 t−1 的交易日排名；起始不足五日及窗口内缺失排名时，按有效记录取平均。

第 16 页目前采用[按年末收盘净值切分的收益](../20260916_calendar_year_returns/README.md)，分别展示 2025 年和 2026 年截至 8 月 28 日的不扣费收益、扣费后收益、日均单边换手与年度净收益曲线。上面的 `year_slices.csv` 按建仓年份划分，作为历史结果保留；页面生成器直接读取研究仓库中的新分年结果。
