## 解释边界

全部结论仅适用于三轮训练预算与固定 0.05 系数。差异不显著不代表效果等价。多空 Sharpe 未扣交易成本，仅作因子诊断。

相同系数不等于相同有效梯度强度。本轮回答直接替换的效果，不证明分别调参后的最优性能，也不证明增加辅助项的必要性。
