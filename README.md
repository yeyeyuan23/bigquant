# BigAlpha 2026 因子研究工程

当前工程只保留已登记候选、共享数据合同、评价规则和最小验证。队友从
[协作手册](docs/team_workflow.md) 开始；研究口径以
[因子选择与评估执行计划](docs/factor_research_plan.md) 为准。

## 当前有效内容

- `docs/factor_research_plan.md`：逐阶段研究、评价、冻结和提交计划；
- `docs/candidate_registry.md`：已登记候选、数据准入状态和最小实现记录；
- `docs/data_contract.md`：AIStudio 数据合同、字段和最小面板验收；
- `src/bigalpha2026/candidates/`：只包含已经登记的候选实现；具体数据核验和评价
  状态以候选登记表为准；
- `src/bigalpha2026/evaluation.py`：与具体候选无关的通用评价工具；
- `src/bigalpha2026/factor_pool.py`：公开库和自研候选的动态左连接、筛选与族平衡；
- `src/bigalpha2026/research_policy.py`：因子池、门槛、代表月份和组合规则的本地唯一事实来源。

## 项目原则

- AIStudio 负责真实数据查询、快照核验、最终短窗验收和提交；
- 本地负责真实快照上的因子评价、组合训练、研究规则、测试和版本控制；
- screened15 日级快照可在队内同步但不进入 Git，原始分钟数据按需最小同步；
- 本地 Python 使用 `quant` 环境；首次 clone 后执行 editable install，之后统一通过
  `conda run --no-capture-output -n quant python` 运行；
- 未登记的候选不实现；
- 严格研究准入与“平台链路冒烟提交”分开记录；冒烟提交不得被表述为已通过交易准入；
- 每个提交 Notebook 只能包含一个因子入口；
- `main()` 只能返回 `date、instrument、factor` 三列。

## 当前结论

四类最小共享面板、2019—2023 年基础包、FR PIT 事件和 HF/OB 日频组件均已通过
AIStudio 与本地双重验收。原八个基础候选的首轮评价已完成；随后按“先跑通最小
组合链路”的独立目的，将 `FR-002` 与 `HF-001` 纳入组合准入观察池。OAP 第一批
新增 `PV-003—019` 和 `FR-003—011`，OAP A级15个和B级11个均已实现。
34个已登记候选按本地S和screened15增量I路由；滚动长窗口允许自然预热，
不要求为了补齐 2019 年而继续下载 2018 年价格数据。`PV-007、FR-007、PV-012`
因截面取值过于离散而未通过技术门槛。

冻结的 `INT-001` 是 `FR-002/HF-001` 各 50% 的日度截面秩组合，本次仅作为平台端到端冒烟版本。2026-07-26，AIStudio 真实数据短窗返回 3,000 行、三列契约、无重复、覆盖率 100%，随后比赛网页确认提交成功；最近一次已记录公榜分数为 `0.57416`、当时团队排名第 `79`。该结果只作为平台反馈，不用于追溯修改冻结权重。

`INT-001` 的冻结提交记录保存在 `artifacts/frozen/int_001.json`。动态入口不硬编码候选：公开库筛选只使用
2019—2021；S/I 决定自研因子进入哪些管线。组合阶段只保留三条隔离管线：
`self_factor_composite`、`joint_elastic_net` 和 `joint_lightgbm`。
`factorlib_screened` 复用 I 评价时缓存的结果作为固定参照，不作为第三个方案
重复训练。逐因子加入只用于准入和消融。I 只使用 2019—2021 开发期决定联合
模型成员；2022 与 2023 是等权跨市场状态验证年，三条管线按较差年份表现优先、
两年均值次优排序。Elastic Net 的增量评价和最终训练都对特征及标签做逐日截面
标准化，并保存滚动窗权重。当前本地第一为 `joint_elastic_net`，2022/2023
Rank IC 为 `0.06913/0.08118`。冻结赢家后再同步到 AIStudio 做短窗验收和提交，
不覆盖已冻结的 `INT-001`。
