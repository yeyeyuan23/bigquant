# 分数输入变化的同口径诊断

为解释五日平均排名从旧表约 14.49% 降到原始分数表 12.17%，在 AutoDL 使用同一个 `raw_engine.py` 重跑两套分数。固定日期、股票资格、价格、执行、估值和费率；原始分数的六组重跑指标与已发布结果逐项一致。12 组均完成，见 `audit.json`。

旧输入是此前保存的完整处理流程：缩尾、标准化、行业与 10 个 Barra 风格中性化；新输入是模型原始输出。本诊断比较两个完整流程，并未单独识别每一步处理的边际作用。

| 五日平均排名 | 旧中性化处理流程 | 原始模型分数 |
| --- | ---: | ---: |
| 日均单边换手 | 0.515 | 0.429 |
| 毛年化 | 28.68% | 24.07% |
| 净年化 | 14.39% | 12.17% |
| 净 Sharpe | 2.736 | 0.723 |

净年化下降约 2.22 个百分点：毛年化减少约 4.61 个百分点，毛净年化差缩小约 2.38 个百分点。该差值包含费用及扣费后再配置的影响，不是独立的逐笔费用归因。

旧展示使用另一种收益统计口径，给出 14.49%；统一为 402 日收盘净值后是 14.39%。因此此次下降主要不是年化口径变化。

两种输入下，五日规则的目标多头重合率平均为 63.66%，目标空头重合率为 69.68%。中性化改变排序，五日平均后仍有约三分之一的目标股票不同。更低的换手不保证更高的收益。

同一对照中，每日五分位净年化由 -7.62% 升至 2.74%，排名缓冲区由 4.32% 升至 13.65%；不能把五日规则的结果推广为所有规则都应做中性化。具体是哪类行业或风格倾向造成差异，还需要持仓收益归因，本诊断未作此结论。
