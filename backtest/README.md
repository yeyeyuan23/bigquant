# 原始模型分数：策略回测与换手优化

本目录最新实验是 **21 个持仓配置 × 4 种成本情景 = 84 组回测**，已在 AutoDL 全部完成并通过审计。它们使用同一个固定模型、同一份原始分数和行情，比较选股保留带、调仓频率和调整幅度。**21 是持仓规则及其调仓起点的配置数；4 是每个配置分别重跑的成本情景。**

本批基准成本下，净 Sharpe 最高的是 **两端各持有 10%、30% 排名保留带**：日均单边换手 **0.870**，毛年化 **59.66%**，净年化 **35.46%**，净 Sharpe **1.991**，净累计 **71.63%**，最大回撤 **−12.45%**。每日 Q10−Q1 基线的净年化为 **13.52%**、净 Sharpe **0.784**、换手 **1.505**。这是对已观察区间的回顾性比较，尚无独立的策略选择测试集。

阅读入口：[策略细则与复现](docs/TURNOVER_TRIALS.md) · [全部实验索引](results/README.md) · [历史五分位/纯多头说明](docs/RAW_SCORE_BASELINES.md) · [AutoDL 原始审计报告](results/20260917_turnover_trials/README.md)。

## 共同口径

- **信号**：固定提交模型的原始 `factor`，不缩尾、不标准化、不做行业或风格中性化。模型训练截至 2024-12-26，本批没有重新训练。
- **区间**：2025-01-02 至 2026-08-28，402 个交易日；股票池每天 1,000 只，为历史时点的中证 1000 成分股。首日现金，2025-01-03 开盘建仓。
- **交易**：收盘后形成信号，下一交易日开盘调仓，连续持有并计入隔夜涨跌；末日开盘尝试退出，缺开盘报价的持仓无法成交，继续按已知价格估值。
- **敞口**：多头目标 +100%、空头目标 −100%，以扣费后净值为基数，目标总敞口 200%。纯缓冲策略每侧目标 100 只；渐进调仓可保留更多股票；低频策略在不调仓日保持股数，敞口随价格漂移。
- **统计**：由收盘净值计算；年化收益为日收益均值 × 252，**不是 CAGR**；Sharpe 使用样本标准差并年化，无风险利率为零；累计为复利净值减 1。
- **换手**：每日 `(买入成交额 + 卖出成交额) / (2 × 调仓前开盘净值)`，含建仓、实际平仓及首日零换手，平均覆盖全部 402 日。表中 `1.505` 表示 150.5%，在多空总敞口 200% 下可大于 1。

## 21 个持仓配置做了什么

Q1 是原始分数最低的 10%，Q10 是最高的 10%。`10% 持仓 / 30% 保留带` 表示每侧仍目标持有 100 只；原多头只要还在最高 30% 内、原空头还在最低 30% 内就优先保留，再按最新分数补足。它不会持有每侧 300 只。

| 策略族 | 配置数 | 参数 / 配置 ID | 实际规则 |
| --- | ---: | --- | --- |
| 每日十分组基线 | 1 | `daily_decile` | 每日重选最高/最低 10%，每侧等权 |
| 排名缓冲 | 4 | `buffer_10_15/20/25/30` | 每侧持有 10%，保留带依次为 15% / 20% / 25% / 30%，每日等权调仓 |
| 每 2 日调仓 | 2 | `every_2d_phase0/1` | 每 2 个交易日重选十分组，报告两个调仓起点 |
| 每 3 日调仓 | 3 | `every_3d_phase0/1/2` | 每 3 个交易日重选十分组，报告三个调仓起点 |
| 每 5 日调仓 | 5 | `every_5d_phase0/1/2/3/4` | 每 5 个交易日重选十分组，报告五个调仓起点 |
| 每日渐进调仓 | 3 | `partial_25/50/75` | 旧组合与最新十分组目标按 25% / 50% / 75% 混合，再按多空两侧归一 |
| 缓冲 + 渐进 | 1 | `buffer_10_20_partial50` | 20% 保留带 + 每日 50% 渐进调整 |
| 缓冲 + 隔日 | 2 | `buffer_10_20_every2_phase0/1` | 20% 保留带 + 隔日调仓，报告两个起点 |
| **合计** | **21** | **1 + 4 + 2 + 3 + 5 + 3 + 1 + 2** | 全配置逐一列在下表 |

表中的斜杠是同族 ID 的简写，完整 ID 见结果表与 [固定协议](src/protocol_turnover_trials.json)。**相位是首次建仓之后的调仓日历偏移**：所有相位均在首个可交易开盘建仓，不是等到各自相位才入场。渐进比例也不是降低总敞口：混合后仍按多头 +100%、空头 −100% 归一，首次建仓为全量。详细定义见 [执行规则](docs/TURNOVER_TRIALS.md)。

## 4 种成本情景

1bp = 0.01%。滑点按买、卖各侧成交额另加；买入包括加多和回补空头，卖出包括减多和开空。

| 情景 ID | 含义 | 买入费率 | 卖出费率 | 每侧附加滑点 | 买入 / 卖出合计 |
| --- | --- | ---: | ---: | ---: | --- |
| `gross` | 毛收益 | 0bp | 0bp | 0bp | 0bp / 0bp |
| `fees_slip0` | 基准成本 | 3bp | 8bp | 0bp | 3bp / 8bp |
| `fees_slip2` | 基准费用 + 2bp 滑点 | 3bp | 8bp | 2bp | 5bp / 10bp |
| `fees_slip5` | 基准费用 + 5bp 滑点 | 3bp | 8bp | 5bp | 8bp / 13bp |

每个情景独立重跑持仓与净值；毛收益是零费用运行结果。后文“净”指标默认指 `fees_slip0`，额外滑点另列。完整 84 行见 [summary.csv](results/20260917_turnover_trials/summary.csv)。

### 从结果能看到什么

- **排名缓冲**：15% 到 30% 的四个保留带均提高本批净收益和 Sharpe。30% 保留带相对每日基线降低换手 **42.17%**；本批表现随保留带加宽而改善，不能据此推断继续加宽仍然有效。
- **降低频率**：换手降低，但结果明显依赖起点。每 3 日调仓的净年化范围为 **7.52%–25.76%**，每 5 日为 **11.13%–23.11%**。五日相位 4 的换手最低（0.312），最大回撤也达到 **−20.51%**；低换手并不代表整体表现更好。
- **渐进调仓**：25% / 50% / 75% 调整的净年化分别为 **16.70% / 17.03% / 15.77%**，本批均高于每日基线，仍低于四个纯排名缓冲配置。
- **混合规则**：20% 缓冲 + 50% 渐进的净年化 **13.23%**、Sharpe **0.767**，略低于每日基线；缓冲 + 隔日的两相位净年化为 **28.68% / 17.32%**，也有起点依赖。
- **分年**：30% 保留带在 2025 年和 2026 年至 8 月的净年化分别为 **34.99% / 36.18%**，均高于基线的 **10.67% / 17.87%**。2026 年是部分年度；分年统计不重置仓位，也不构成新的未见样本。

## 其他已做的实验

这些批次另有用途，不计入上面的 21 × 4。十分组因子分组评价使用下一日开盘到收盘收益，策略回测则连续持仓、包含隔夜并扣费，两者的数字不能直接混用。

| 历史三规则 | 每日两端 20%、20%/30% 缓冲、五日平均排名；3 × 4 成本 | 基准成本净年化 2.74% / 13.65% / 12.17% | [原始分数基线](results/20260916_raw_scores/README.md) |

| 每日十分组策略 | 每侧 10%，先跑毛收益与基准成本，作为本批基线 | 净年化 13.52%、Sharpe 0.784 | [Q10−Q1 策略](results/20260917_decile_strategy_preview/README.md) |

| 历史分数输入诊断 | 历史处理流程与原始分数在同一引擎下对照 | 五日排名净年化 14.39% → 12.17%；未单独识别中性化的边际效果 | [输入诊断](results/20260916_score_input_comparison/README.md) |

## 完成记录与边界

[status.json](results/20260917_turnover_trials/status.json) 记录 `complete / 84 / 84 / passed`；[audit.json](results/20260917_turnover_trials/audit.json) 核对逐日费用、净值、损益及分年指标。14 项原引擎测试和 8 项规则测试通过；30% 保留带另经 400 日目标持仓核对及未来输入扰动检查，见 [候选审计](results/20260917_turnover_trials/candidate_audit.json)。来源和收回哈希见 [execution.json](results/20260917_turnover_trials/execution.json)、[collection.json](results/20260917_turnover_trials/collection.json)。

这些检查验证计算与时序一致性。策略选择已经看过该区间；当前最高 Sharpe 只代表本批、本区间的比较结果。交易使用理想化开盘参考价并假设可卖空，未模拟借券/融资费用、非线性冲击、涨跌停排队及容量。部分低频和渐进配置在期末因缺报价留有持仓，`summary.csv` 的 `terminal_residual_value` 保存其绝对市值；期末净值包含估值，不等于全部变现所得。
