# 因子候选登记表

登记日期：2026-07-25

本表前半部分登记机制、数据依赖和准入边界，不在登记阶段根据历史结果调整方向；后半部分保留已经发生的技术验收和诊断记录。真实数据字段均在网页 AIStudio 用短窗查询核验；`data_checked` 仅代表数据可实现，不代表因子有效。

## 共享数据规则

- 研究面板以 `bigalpha_2026_instruments` 为左表，池内停牌仍保留，不能用分钟表反推股票池。
- `bigalpha_2026_stock_bar1m` 的 `volume、amount、deal_number` 是分钟增量，日频量按日求和。
- 五档盘口只使用价格和数量均为正的有效档位，并保留有效档数。Step 0 v2 在 2024-01-02 历史股票池内 239,280 个活跃快照中复核：双侧至少各一档有效报价占 99.757606%，双侧完整五档占 98.917586%；空档不能当成零价真实报价。
- `bigalpha_2026_financial` 是披露事件表。财务值按披露可见日 backward as-of；`total_assets` 只使用 `lf`，其他流量字段必须显式指定 `lf、mrq` 或 `ttm`。
- 未知日内披露时间的财务数据，保守地从披露日后的首个中国交易日生效。
- 所有下一期标签先按 `all_trading_days` 的 CN 日历映射下一交易日，再连接收益；停牌造成标签缺失，不向后跳日。
- 风险暴露只用于风险控制、分层或增量检验，不作为候选机制本身。

## Step 1 固定基础矩阵

Step 1 于 2026-07-25 按 Step 0 v2 数据合同重新登记完成。基础候选固定为四个数据族、每族两个机制：

- 八个基础候选的主数据族、机制、方向和预测周期在 2019—2022 正式评价前锁定。

## Step 2 最小实现记录

### PV-001
