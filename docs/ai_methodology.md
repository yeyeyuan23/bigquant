# AI智能赛道复现与审计记录

## 1. AI参与环节

AI用于限定经济机制内的候选公式生成、窗口选择、消融解释和候选淘汰，不在私榜运行时调用外部模型或网络。最终提交的是冻结、确定性的公式。

两个允许搜索的机制家族：

1. `PERSISTENT_BOOK_PRESSURE_UNDERREACTION`
2. `PIT_QUALITY_FLOW_CONFIRMATION`

搜索空间以 `configs/search_space.json` 为唯一事实来源，共48个候选。禁止AI添加未在配置中声明的数据、未来收益输入或无经济解释的深层组合。

## 2. 固定Prompt

```text
你是受约束的A股微观结构因子研究器。只能在给定机制家族、窗口、
盘口档位和算子集合内提出候选；每个候选必须说明经济机制、数据时点、
预期方向、可能失效环境和与常见因子的重复风险。不得查看2024冻结
检验结果后修改公式，不得使用未来数据，不得调用比赛外部数据。
```

## 3. 数据与时间纪律

- 2019—2022：候选生成和初筛；
- 2023：公式及参数选择；
- 2024：冻结检验，只读取一次；
- 财务数据以PIT披露日期生效；
- \(t\) 日因子只能使用 \(t\) 日及以前可获得的信息；
- 原始比赛数据不得导出AIStudio。

## 5. 冻结决策

最终Notebook中需记录：

- 源候选ID；
- 选择日期；
- 选择前使用过的数据区间；
- 三种收益标签下的方向；
- Elastic Net非零窗口比例；
- 与基础因子库的最高Rank相关性；
- 两个候选之间的Rank相关性；
- 公式冻结后的任何修改及原因。

## 6. 已知局限

- 官方未公开下一期收益的精确成交口径；
- DAI字段版本可能调整，提交前必须小样本核对；
- 盘口快照无法完全区分成交、撤单和新增委托；
- 公榜反馈属于可反复观察的信息，不作为重新扩大搜索空间的依据。
