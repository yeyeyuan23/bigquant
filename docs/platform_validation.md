# AIStudio平台验证清单

## 小样本字段核验

先查询一个交易日、两只股票，确认：

- `volume`、`amount` 为当日累计值，盘中单调递增，跨日重置；
- `time` 使用 `HHMMSSmmm`；
- `close` 是分钟收盘/最新成交价；
- 1—10档价格、数量字段名称与数据页一致；
- 财务表 `date` 是公告日，`report_date` 是报告期；
- `category` 提供 `ttm / mrq / lf`，`shift` 是报告期偏移；
- 当前实现固定使用 `category=ttm, shift=0` 的现金流、利润和收入；
- 当前实现固定使用同公告日、同报告期 `category=lf, shift=0` 的总资产。

## 资源和运行

1. 小样本使用1C/6G验证字段和公式；
2. 完整历史切换4C/16G；
3. 先运行12组 `(depth, tail_minutes)` DAI日频聚合缓存；
4. 再在日频结果上生成48个候选，避免重复扫描分钟表；
5. 记录每组查询耗时、峰值内存和失败日志；
6. 完整提交目标小于60分钟，硬上限3小时。

## 研究输出

平台内保存但不对外导出：

- 候选准入表；
- 60日/20日滚动Elastic Net权重；
- 候选与基础因子库Rank相关矩阵；
- 三种收益标签结果；
- 年度、行业和压力期IC；
- 最终两个候选ID及冻结时间。
